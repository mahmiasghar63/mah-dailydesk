# Contributing to MAH DailyDesk

Thanks for helping improve the app. Keep submissions focused and useful to everyday users.

1. Open an issue or explain the bug/feature in your pull request.
2. Use clear, self-contained Python functions and preserve local-first storage.
3. Add or update tests when modifying data logic.
4. Run `python -m pytest -q tests/test_storage.py` and, when available, the GUI smoke test.
5. Don't commit generated SQLite data, backups, virtual environments, build output, secrets, or screenshots containing personal information.

Please keep UI changes accessible, keyboard-friendly, and consistent with the existing design system.
