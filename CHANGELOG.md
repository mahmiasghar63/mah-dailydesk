# Changelog

## 1.0.0 — First Windows release

- Added reproducible Windows GitHub Actions release build (PyInstaller, 64-bit).
- Added an original matching application icon and brand artwork.
- Added packaged executable startup checks and disposable-data GUI screenshots.
- Added downloadable Windows app ZIP, release checksums, and release notes.
- Verified the Python source was launched successfully on Windows by the project owner.
- Eight offline-first sections: dashboard, tasks, notes, planner, habits, expenses, focus and settings.

**Note:** Windows binaries are unsigned. Keep the full extracted application folder intact.

## 0.1.0 — Source preview

- First version of MAH DailyDesk with eight offline-first productivity pages.
- Global keyboard shortcuts and command palette.
- SQLite persistence with manual backup and CSV export.
- Multi-theme design system with four selectable accents.
- Database unit tests and an optional headless Qt smoke test.
